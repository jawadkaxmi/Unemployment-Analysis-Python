# Unemployment Analysis with Python
### CodeAlpha Data Science Internship — Task 2

## Overview
Analysis of India's unemployment rate data using Python, investigating the impact of COVID-19 on unemployment trends.

## Key Findings
- Overall average unemployment rate: 11.79%
- Pre-COVID unemployment rate: 9.51%
- During COVID unemployment rate: 17.77%
- COVID-19 increased unemployment by: 8.26%
- Highest unemployment region: Tripura
- Lowest unemployment region: Meghalaya
- Peak unemployment month: May 2020 at 24.88%

## Visualizations
- Average Unemployment Rate Over Time
- COVID-19 Impact Comparison (Pre vs During)
- Top 10 Regions by Unemployment Rate
- Rural vs Urban Unemployment Distribution
